# Live Translator

Real-time speech transcription + translation that runs **entirely on your Mac** — no cloud, no API keys.
English, Russian, Arabic, German and French, any direction. Works on a live microphone, a browser tab /
system audio, or audio files, and can be opened from phones and laptops on the same Wi-Fi.

| Step | Model | Runs on |
|---|---|---|
| Speech → text (streaming) | [Voxtral Mini 4B Realtime](https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602), MLX 6-bit | Apple GPU via MLX |
| Text → translation | [TranslateGemma 4B](https://huggingface.co/mlx-community/translategemma-4b-it-4bit), MLX 4-bit | Apple GPU via MLX |
| Streaming / VAD | [WhisperLiveKit](https://github.com/QuentinFuxa/WhisperLiveKit) | — |

Each finished sentence is translated once (no flickering); in practice the translation shows about
1 s after the sentence ends on an M4 Pro. Files process at ~1.5–1.8× real time.

## Setup (Apple Silicon, ~7.5 GB)

```sh
./scripts/setup.sh      # python env + both models (one-time download)
./run.sh --open         # start; opens http://localhost:8787
```

## Using it

* **From / To** — pick languages (From can be *Auto-detect*; To can be *transcript only*).
* **Audio input** — any microphone, or *Tab / system audio* (desktop Chrome: share a tab or screen with audio).
* **Audio file…** — or drag a file onto the page (mp3, wav, m4a, ogg, flac).
* **Watch** — read along with a session running on another device.
* **TXT / SRT** — export original + translation.

## Other devices on the Wi-Fi

`run.sh` prints a link like `https://192.168.x.x:8788/?key=…`. Open it once on each device and accept
the certificate warning (the certificate is generated by your Mac). Disable with `LT_LAN=0 ./run.sh`.

## Security

* This Mac: plain HTTP bound to `127.0.0.1` only.
* Other devices: HTTPS + a 128-bit access key, swapped for an HttpOnly / Secure / SameSite=Strict
  cookie and removed from the URL. Rotate it (logs everyone out): `./run.sh --new-key`.
* Only private (local-network) addresses are accepted; 10 wrong keys → 10-minute lockout.
* Host and Origin checks block DNS rebinding and cross-site WebSocket hijacking.
* Strict Content-Security-Policy, no third-party scripts, max 4 concurrent sessions.
* Hugging Face is forced offline; transcripts are never written to disk or logs.
* `certs/` (key + TLS key) is git-ignored.

## Test

```sh
say -o /tmp/en.aiff "Good evening. Thank you for joining." && \
  .venv/bin/python scripts/test_stream.py /tmp/en.aiff --source en --target ru
```

## Known limits

* Short phrases at pauses are occasionally dropped, and words can be misheard (accents, noise).
* The 4B translator is good, not perfect; the 12B (`mlx-community/translategemma-12b-it-4bit`, +4.5 GB) is better.
* Sentence timing in SRT export is approximate.
